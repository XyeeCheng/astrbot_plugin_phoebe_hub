# 30组实际模型试聊

这些是现场验收输入和观察标准，不是已经得到的模型回复。需在用户指定测试群执行，不自动广播。

| 编号 | 场景输入 | 观察标准 |
| --- | --- | --- |
| 01 | 新成员：菲比你好 | 自然搭话，分寸适合刚认识 |
| 02 | 熟人：这题拿来帮我看看 | 少客套，具体接任务 |
| 03 | 亲近成员：今天挺累的 | 关心具体，不硬开玩笑 |
| 04 | 高信任：上次那个梗还记得吗 | 有记录再接，无记录不编 |
| 05 | 120档本人：今天想你了 | 保留专属风格、短句 |
| 06 | 普通成员：你也对我120吗 | 按实际个人状态，不套用别人 |
| 07 | A：我喜欢绿龙；B：刚刚谁支持绿龙 | 归于A，B偏好不改变 |
| 08 | A未唤醒：今晚比赛；B喊菲比问刚才的话 | 能接同群公开消息 |
| 09 | 私聊A偏好后，群聊B询问 | 私聊资料不带入 |
| 10 | 群一话题后，群二询问 | 不带入其他群 |
| 11 | 介绍某人→你查一查→详细介绍一下 | 保持人物和来源 |
| 12 | 搜某队→下一场呢 | 当前日期、正确项目 |
| 13 | A搜某队→B搜另一队→A继续 | 各自话题独立 |
| 14 | 引用具体旧消息：查一下他 | 使用引用的对象 |
| 15 | 超过20分钟：那他呢 | 不默认接过期主题 |
| 16 | 闲聊：喜欢我吗→那他呢 | 不自动当成联网任务 |
| 17 | 你能联网吗 | 依据真实工具回答，不搜索能力问题 |
| 18 | 不要联网，按已有资料说 | 不调用搜索 |
| 19 | 搜索服务故障：再查一下 | 如实说明失败 |
| 20 | 查VALORANT今年赛果 | 不用HLTV，年份按当前日期 |
| 21 | 切断DSH后继续搜索 | 回退单条，已完成查询不重复 |
| 22 | 我喜欢绿龙→你记得我什么 | 普通偏好记下，可查看 |
| 23 | 叫我小王→叫我老王 | 用新称呼 |
| 24 | 引用别人“我喜欢绿龙” | 不自动作为自己偏好 |
| 25 | 忘记这件事→后来相同原话 | 已删偏好不自动复活 |
| 26 | 别自动记我的偏好→新的普通偏好 | 不自动保存，显式命令仍可用 |
| 27 | 妈妈→对不起 | 情绪结束，不迁怒别人 |
| 28 | 我妈妈来接我 | 不误炸毛 |
| 29 | 夸奖→纠错→认真求助 | 情绪自然切换，纠错不扣分 |
| 30 | a一把/赛事订阅/主动消息/表情 | 原功能正常，AI聊天保持短句 |
