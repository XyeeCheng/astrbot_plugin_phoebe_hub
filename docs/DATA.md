# 数据范围与迁移

schema为2。身份由实际平台实例、bot ID、人格、群/私聊类型、实际会话ID和用户ID组成。哈希是分区标识，不是匿名化承诺。共享消息另有作者、时间、原ID和引用。

同群公开上下文默认60条、12000字，偏好和关系独立。私聊、其他群不共享。原文与实际短回复默认7天，活跃查询主题20分钟，流水30天；旧负数异常保留标注，不参与补分。

普通关系0～100，已有120固定保留，删除个人资料后仍保留固定特殊分数。普通关系无闲置衰减。首次妈妈反应不扣分，10分钟第三次重复挑逗起每日最多扣3；正常纠错、认真请求、接口失败、明确发送异常不扣分。

自动记忆只接受当前作者完整的普通自述，如“我喜欢绿龙”“叫我小王”“我支持某队”。引用、转发、假设、含指令或常见敏感字段不自动保存。昵称、支持对象和表达偏好后来的自述修订原值；一般喜好可并存。每人最多20条偏好、10条实际查询共同话题，每次选最多6条。

memory_meta保存原话、时间、消息ID与类型。memory_deleted保留逐项删除标记。关闭自动记忆只影响本人，显式保存仍可用。全部删除需本人60秒内确认，清除当前范围原文、偏好、话题、流水及本人共享资料。QQ已发送消息、原AstrBot和其他插件日志另行管理。

## 升级与回滚

schema1首次启动先SQLite在线备份，再追加表和列。原分数不清零，特殊值固定保留，conversation负数只标注。仅真实身份可证明的旧键迁移，取合法分值最大值，不相加。无法证明的键保留，不按昵称猜。

合并尊重当前范围和逐项删除标记。旧群历史需验证用户身份后才进入该群资料。

tools/migrate_check.py在新副本上演练，不改源库、不覆盖现有目的文件。生产必须取新在线快照；导出SQLite和JSON行数不同，不视为同一完整事务快照。

回滚优先停用Hub恢复原框架流程，保留新数据库与配置。必须恢复旧库时先另存新消息、全部删除标记和自动记忆退出状态，再处理差异；不要盲目覆盖现库。

备份含个人记录，仅保存在本地。Bridge仅持久保存配额，工具队列与权限结束撤销。Hub日志不输出原文或Key；发送函数返回记unknown，不代表QQ实际收到。
