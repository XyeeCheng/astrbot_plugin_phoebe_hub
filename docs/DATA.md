# 数据范围

- 关系键由平台实例、bot自身ID、人格ID、完整会话类型/ID、用户ID组成，再做SHA256。哈希是分区标识，不是匿名化承诺。
- 分数、明确偏好保留至本人删除。聊天原文/短回复默认保留7天、记分流水30天；清理任务每小时执行。消息中不要保存凭据，显式记忆命令拒绝常见密码/Key字段。
- 上下文最多最近8轮；只包含相同关系范围的对话。不自动读取旧AstrBot群历史，不用昵称合并不同人。
- `忘记我`只清除本人**当前会话、当前人格**记录。私聊、其他群或人格分区需在相应范围分别删除。
- DSH运行资料只在单次临时目录存在，任务结束清理；Bridge持久保存每日请求计数，不保存请求正文和回答。
- Hub日志只输出状态与异常类型，不输出Key、原文或上游错误详情。模型和平台自身的日志/已发送群消息由其各自管理。
- 主动聊天由原Proactive Chat插件保留自己的历史和调度数据，Hub不取得这些数据的所有权。删除Hub记录不会清空原插件或QQ的聊天历史。

## 备份与删除记录

`备份数据` 使用SQLite在线备份，包含个人记录，应仅保存在本机；不把备份文件发到群或GitHub。

`tombstones`表保留删除范围的哈希与删除时间，避免恢复旧备份时忘记已删除的范围。当前版本不提供自动覆盖式恢复命令；人工恢复时必须先停用Hub，并将现库的tombstones与备份合并，再删除对应旧记录。不要直接把更早备份覆盖现库来恢复，否则可能恢复已经删除的资料。

清除失败或迟到回复不会重新写入已删除的记录。正常命令与聊天按同范围串行处理；热重载会取消尚未完成的Hub请求并关闭资源。
