# 升级到1.1.0

本版合并补充导出包中的联网逻辑与120档专属人格，修复请求内容丢失和联网追问，普通成员采用自然关系成长。离线开发不等同服务器已部署。

## 备份和演练

先在菲比实例“备份数据”，保存当前插件目录和配置。确认只操作菲比容器与数据目录。

执行python tools/migrate_check.py 源库路径 新副本路径。目的文件必须不存在；结果需scores_preserved为true、integrity为ok、schema为2。

导出JSON副本演练保留全部19个关系分数；120在新互动后仍120；七条−20只标注，不补加140。该副本用于复现，不能替换生产库。

## 安装

在菲比AstrBot管理页停用Hub，把1.1.0安装包导入同名插件，保留Hub数据与配置。首轮建议engine=native，其他模型/工具沿用配置；重载后查看状态为1.1.0。新增默认值：共享60条/12000字、话题1200秒、自动记普通偏好开启，成员可自行退出。

继续DSH时，在现有Bridge目录保存.env、secrets和网络设置，用新源码重建dsh服务，保留原模型/凭据/配额卷。健康接口含tool_protocol: 2后改回engine=dsh；旧Bridge回退原生。不要停其他机器人或覆盖游戏/余额/赛事资料。

## 指定群验收

- A提话题、B能接上，作者准确；其他群与私聊不混入。
- 用户本人仍120，普通成员旧分保持，偏好与情绪独立。
- “介绍某人”→“你查一查”→“详细介绍一下”，实际查询与主题延续；20分钟后不沿用过期主题。
- 能否联网根据真实工具回答；不要联网不调用；失败如实说明。
- VALORANT不进HLTV，来源和年份核对。
- 偏好保存、修订、删除与退出自动记忆可用。
- 炸毛/道歉、短回复、游戏、赛事、主动聊天、表情正常。
- 原生与DSH各查询一次，回退单条回复，不重复已完成的同参数查询。

口吻、接梗、真实API与QQ实收需在实际模型和用户指定群验证；本地模拟不能替代。

## 回滚

先停用Hub恢复原框架，保留升级后库。退回旧代码前保存新消息和删除标记，不直接覆盖旧db。DSH可单独停止，不停整个Docker。
