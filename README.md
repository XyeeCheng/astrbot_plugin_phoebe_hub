# 菲比 Hub 1.1.1

AstrBot 菲比对话增强：同群接话、自然关系成长、个人偏好与情绪、联网追问、短回复。默认强傲娇，导入的专属120分和对应人格保留。要求 AstrBot ≥4.28.1、Python ≥3.11。

源码仓库：[astrbot_plugin_phoebe_hub](https://github.com/XyeeCheng/astrbot_plugin_phoebe_hub)，安装包见[v1.1.1 发布页](https://github.com/XyeeCheng/astrbot_plugin_phoebe_hub/releases/tag/v1.1.1)。已有1.1.0实例按[补丁升级说明](docs/UPGRADE_1_1_1.md)更新插件，保留现有配置、数据库和已经支持工具协议2的Bridge。

## 1.1.1修复

“你怎么看VCTcn2-16”等赛事评价先查事实；普通私人评价不会因“怎么看/怎么样”被强制联网。赛事话题后只问“你怎么看？”可承接当前成员的有效话题。

压缩长回复时同时传入原问题、本轮成功工具资料和当前关系口吻，包含模型自行决定执行的查询。只因换行超出句数时完整合并换行；不会截取前两句而丢弃后文订正。清理推理标签后再计算正文预算。

失败时不再要求重复问题；已经查到资料则保留真实来源并说明回答整理失败。日志区分实际引擎、预先查询是否必需、实际工具结果、压缩结果与超时/异常类型。查过资料的回复来源来自本轮成功工具结果。

本次不修改数据库结构、好感度计算或Bridge协议，120固定分数保持。见[补丁验证记录](docs/VALIDATION_1_1_1.md)。

## 这次升级

| 功能 | 行为 |
| --- | --- |
| 同群上下文 | 默认最近60条、最多12000字，标注作者ID、昵称、北京时间、消息ID和引用，未唤醒的群聊也可作为资料 |
| 原请求 | 原生引擎保留完整框架请求、上下文、额外消息组件、工具说明、图片和音频；最终短回复写回框架会话 |
| 联网 | 明确查询和时效性问题先查；“查一查”“详细介绍一下”“那他呢”延续当前成员的话题，默认20分钟过期 |
| 查询真实性 | 记录实际工具、调用和结果；查询失败不能包装成查到了；VALORANT话题排除CS的HLTV工具 |
| 好感度 | 普通0～100，初始20；10分钟最多+1、北京时间每日最多+5，无闲置衰减；有效短追问可成长 |
| 专属分数 | 120保留为固定特殊值，不参与普通加减分；旧−20异常保留标注，不补加140 |
| 身份 | 实际平台实例、机器人、人格、群/私聊、会话ID、用户ID；称呼、前缀及引擎不改变身份 |
| 个人记忆 | 明确的普通偏好自动记忆，保存原话、消息ID和时间；昵称/支持对象/表达偏好可修订，每人可退出 |
| 共同话题 | 成功查询留下个人共同话题，最多10条；每次选相关偏好与话题，最多6条 |
| 临时情绪 | 正常、开心、害羞、炸毛、认真，与长期关系分开；炸毛最多120秒或两次回复，道歉/认真点结束 |
| DSH | 固定SDK/runtime 0.1.5rc1，认证通道调用允许的AstrBot只读工具；失败回退复用已查结果 |

普通阶段：0～19保持距离，20～34刚认识，35～49聊得来，50～64熟人，65～79很亲近，80～100很信任。普通高好感不自动变成恋爱关系；原有120档沿用专属角色设置。

分数、偏好、情绪各自独立。公开原话只在同群使用；私聊不供其他成员使用。不按昵称合并旧记录，只有真实身份能证明的旧键才迁移。

## 命令

群聊按原配置 @ 或唤醒菲比，名称后的空格可省略。

| 命令 | 用途 |
| --- | --- |
| 菲比好感度 | 自己的分数与阶段 |
| 菲比你记得我什么 | 查看偏好 |
| 菲比我们的共同话题 | 查看共同话题 |
| 菲比最近为什么变了 | 最近变动，旧异常单独说明 |
| 菲比记住 内容 | 显式保存 |
| 菲比忘记这件事 完整条目 | 删除并防止自动重写 |
| 菲比别自动记我的偏好 | 关闭自己的自动记忆，显式保存仍可用 |
| 菲比恢复自动记我的偏好 | 重新开启 |
| 菲比忘记我 → 菲比确认忘记我 | 60秒内确认，删当前范围个人记录及本人共享上下文；固定特殊分数保留 |
| 菲比认真点 | 结束炸毛 |
| 菲比系统状态 / 菲比备份数据 | 管理员查看 / 在线备份 |

聊天正文1～2句、最多100字，最多附一个来源URL；确定性列表命令可稍长。a一把、弗一把、赛事订阅继续交给原插件。主动聊天仅适配已验证方法签名；表情只读、最多一张。
