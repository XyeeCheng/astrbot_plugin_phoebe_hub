# 菲比 Hub

AstrBot 的傲娇人格与对话增强插件，支持 Ubuntu。默认 **强傲娇**：爱逞强、被夸时嘴硬、熟人面前欠欠的，认真求助时会收住。

> 你：菲比，你好厉害。
>
> 菲比：现在才发现我厉害啊？……再夸一句也不是不行。
>
> 你：妈妈！
>
> 菲比：谁是你妈妈啊？认亲都认到修会来了是吧。

## 安装

AstrBot 管理页 → 插件 → 从链接安装：

```text
https://github.com/XyeeCheng/astrbot_plugin_phoebe_hub
```

要求 AstrBot **≥4.28.1**、Python **≥3.11**。安装后默认使用现有聊天模型，不必安装 DSH，也不用重新填模型 Key。

插件设置中默认 `tsundere_level=3`、`engine=native`。首次可通过 `allowed_sessions` 限制测试会话；管理员发送 `菲比 系统状态` 查看会话标识。群聊按现有唤醒规则，需要 @ 或唤醒机器人。

## 已实现

| 功能 | 行为 |
| --- | --- |
| 好感度 | 0～100，初始20；10分钟最多加1，每日最多加5；按平台实例、bot、人格、会话、用户隔离 |
| 防刷 | 消息 ID 去重、相同内容24小时内不重复加分、无离线扣分；命令和游戏不刷分 |
| 炸毛 | 向菲比喊妈妈/妈咪/麻麻触发；最多两次回复或120秒；60秒冷却；首次不扣长期分 |
| 重复挑逗 | 10分钟第三次起每次扣1，每日最多扣3；道歉不加分 |
| 短回复 | AI 正文1～2句、最多100字；先检查，再最多压缩一次，失败使用短句说明 |
| 记忆 | 用户明确保存、查看、逐条删除或确认全部删除；只在自己的当前会话生效 |
| 上下文 | 每人独立保留最近8轮实际输出；不导入混杂群成员的旧人格历史 |
| 工具 | 使用现有模型与配置好的只读工具，默认允许 Tavily 搜索/正文读取和 query_hltv |
| 主动聊天 | 对已验证方法签名的 Proactive Chat 适配生成与发送；统一短句、一条文本、不分段不TTS |
| 表情 | 可只读使用 meme_manager 当前表情库；按匹配分类最多附一张，不改库、不上传图片 |
| DeepSeek Harness | 可选独立 Bridge，实际 SDK/runtime，内置只读时间插件；失败可回退现有模型 |

默认阶段：有点戒备 → 刚熟悉 → 聊得来 → 熟人 → 很信任。高好感不改变工具权限，不自动建立恋爱或家长关系。

“我妈妈来接我”、引用和解释妈妈这个词不触发；“认真点”“对不起”“别闹了”会结束临时炸毛。其他人的回复不受某个人惹她生气影响。

## 命令

群聊示例均先 @ 机器人。

| 命令 | 用途 |
| --- | --- |
| `菲比 好感度` | 当前会话中自己的分值与阶段 |
| `菲比 记住 我喜欢绿龙` | 保存自己的明确偏好 |
| `菲比 你记得我什么` | 查看已保存条目 |
| `菲比 忘记这件事 我喜欢绿龙` | 按完整条目删除 |
| `菲比 忘记我` → `菲比 确认忘记我` | 60秒内本人确认，清除当前会话关系、记忆、Hub历史 |
| `菲比 认真点` | 结束炸毛 |
| `菲比 系统状态` | 管理员查看引擎、适配状态与会话标识 |
| `菲比 备份数据` | 管理员创建本地 SQLite 在线备份 |
| `菲比帮助` | 功能提示 |

状态、记忆列表等确定性命令不受聊天的两句限制。`a一把`、弗一把、赛事等其他插件命令不由 Hub 处理。

## 重要行为边界

- Hub 接管符合唤醒条件的 LLM 对话，使用自己的上下文与人格；原 AstrBot 人格记录不会被覆盖。暂时停用 Hub 即回到原对话路径。
- 聊天通过单一出口发送，不用原框架的流式、分段、TTS或其他响应装饰链；已提供主动聊天与表情库的专门适配。
- `proactive_adapter=active` 才表示发现了匹配的适配接口；`incompatible` 必须检查目标插件版本，不能据此宣称主动消息已受控。它不会新增订阅、开启主动聊天或修改群目标。
- 表情按现有分类目录读取：生气/愤怒/炸毛/angry；开心/傲娇/得意/happy/shy。没有匹配图片就只发文本，图片不随本仓库分发。
- 只读工具必须先由原插件安装和配置，并在 Hub 的 `tool_allowlist` 中精确列出；不能添加群管、发送消息、文件修改等有副作用工具。当前不自动暴露全部插件工具。
- DSH 默认只带 `phoebe_time`；既有 Tavily/赛事工具继续由 `native` 引擎使用。DSH 不会自动继承 AstrBot 工具，后续接入见[扩展说明](docs/DSH.md)。含图片或音频的请求走现有模型。
- 好感度由代码计算，不让模型自行决定加减分。插件没有修改群成员、文件或主机权限的工具。
- 返回自平台发送函数不代表 QQ 收件人已读/实际收到。发送异常不自动重发，防止重复刷群。
- 代码保证输出形式；是否自然、是否答得准确仍取决于模型。压缩改写也需要在实际使用中观察。
